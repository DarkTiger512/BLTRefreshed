# BLT Twitch Integration

This directory contains the design, inventory, protocol, deployment, migration, and release-readiness material for the managed Twitch Overlay Extension. Everything remains isolated on `BLT/twitch-integration` until the replacement criteria are met.

## Layout

- `inventory/` — generated command, reward, setting, and component catalogs.
- `design/` — accepted ImageGen concept and fidelity notes.
- `protocol/` — versioned action and transport schemas.
- `operations/` — pairing, deployment, security, and monitoring guidance.
- `readiness/` — parity matrix, migration guide, and final release checklist.
